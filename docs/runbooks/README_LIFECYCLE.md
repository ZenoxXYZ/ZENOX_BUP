# README Lifecycle

The README begins as generic repository orientation. After `problem.md` and `plan.md` are approved and `execute.md` is initialized, transition it to the actual challenge: project summary, approved scope, architecture, selected setup, tests, and verified status. Keep any included starter setup optional and link it only when the chosen challenge design uses it.

After Golden-Path implementation stabilizes, reconcile it against code, tests, migrations, runtime behavior, selected release path, deployment evidence if used, limitations, and deferrals. Do not claim planned behavior as implemented.
