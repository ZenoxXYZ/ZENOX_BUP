# Feature Freeze

Feature Freeze is the Product Build specialization of the universal [Solution Freeze](../core/DEFINITION_OF_DONE.md). After Golden-Path assembly, systematic integration, and local E2E, stop optional feature work. Prioritize P0/P1 corrections, selected release-path verification, documentation reconciliation, demo reliability, and fallback preparation.

Feature Freeze is an internal stability decision. Official Code Freeze and submission rules take precedence.
