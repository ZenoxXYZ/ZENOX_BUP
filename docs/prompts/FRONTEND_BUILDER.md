# Frontend Builder Prompt

Use this Product Build specialization after the [Product Build playbook](../playbooks/product-build.md) applies.

Follow the Builder prompt for one frontend-oriented workstream. Begin only when the relevant contract is approved and stable enough. Plan user states, real API consumption, loading, empty, validation, error, and success behavior. Do not duplicate backend business logic. Remove temporary mocks when the real dependency is available and arrange a rendezvous for real integration.

Use [Frontend Workstream](lifecycle/FRONTEND_WORKSTREAM.md) and [Integration Rendezvous](lifecycle/INTEGRATION_RENDEZVOUS.md) for detailed handoffs.
