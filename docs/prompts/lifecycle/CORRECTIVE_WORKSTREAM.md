# Corrective Workstream Prompt

## Use

For a human-approved finding that materially affects architecture, data, API, policy, deployment, or scope.

```text
Read AGENTS.md, the Builder workflow, approved review finding [FINDING IDs OR EVIDENCE], requirements/design, and repository evidence. Produce a corrective Builder plan covering the violated invariant, affected architecture/data/API/policy/deployment behavior, decisions required, scope, deferrals, migration and compatibility implications, tests, verification, and risks. Do not implement until the human approves the plan.
```
