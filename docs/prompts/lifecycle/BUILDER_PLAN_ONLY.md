Propose a bounded plan for [WORKSTREAM NAME]: objective, Critical-Proof-Path relationship, rules addressed, verified current state, design decisions, scope, deferrals, affected artifacts/layers, governing Interface / Assumption Contracts and readiness, dependencies, integration applicability or N/A rationale, required evidence, verification, risks, exit criteria, and branch/worktree decision. Add Product Build Golden-Path, frontend/backend, persistence, or migration considerations only where applicable. Stop before implementation for Human / Project Owner approval.
