# Debugging Prompt

## Use

For an implementation or integration failure.

```text
For [SYMPTOM], reproduce or verify the failure; record expected and actual behavior; inspect repository evidence; trace user action, frontend state, request, route, validation, service/logic, persistence, response, and rendering where relevant; and identify the root cause.

Propose or implement only the smallest approved design-preserving fix. Add regression coverage, run focused and broader verification, and assign a stable BUG-ID only after evidence confirms a bug. Escalate material architecture, schema, API, policy, deployment, dependency, or scope changes for human approval. Do not commit or push.
```
