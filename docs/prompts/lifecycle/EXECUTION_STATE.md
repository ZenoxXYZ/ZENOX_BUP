# Execution State Prompt

## Use

After Master System Design approval.

```text
Read AGENTS.md, the Builder workflow, official rules when supplied, approved problem.md and plan.md, state files, and repository evidence. Initialize or reconcile execute.md and review.md only where verified evidence supports it.

Derive each workstream from plan.md. Track objective, Critical-Proof-Path relationship, Primary Owner and optional contributors, dependencies, governing Interface / Assumption Contracts, required artifact and evidence, integration applicability or N/A rationale, canonical status, exit criteria, and blockers. Record Local Complete, Merge Ready only where the repository workflow uses branches/PRs, and Workstream Complete as separate gates. Add Product Build Golden-Path or layer detail only where applicable. Do not implement product behavior, change architecture, commit, or push.
```
