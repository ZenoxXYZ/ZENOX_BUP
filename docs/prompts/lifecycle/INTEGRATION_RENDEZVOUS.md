# Integration Rendezvous Prompt

> **Product Build specialization.** See the [Product Build playbook](../../playbooks/product-build.md) for selection and routing.

## Use

For Product Build frontend/backend slices after the universal rendezvous has been identified as applicable.

```text
Read AGENTS.md, the Builder workflow, full-stack/API-contract guides, approved problem.md/plan.md, frontend/backend code, contracts, tests, migrations, configuration, and Git evidence. Plan systematic hardening of the assembled Golden Path; this is not the first time frontend and backend meet. For non-Product-Build boundaries, use the canonical [Workstreams](../../core/WORKSTREAMS.md) rendezvous model.

Inspect endpoint/path/method mismatch, request/response fields, status/error behavior, API base URL, CORS, environment configuration, loading/empty/error/success states, mutation/refetch, stale state, backend validation, persistence, refresh/reload, cross-page continuity, mock removal, browser Network evidence, and Golden-Path continuity. Identify boundary owners, mismatch risks, tests, scope, deferrals, deployment implications, and completion criteria. Stop before implementation for human approval.
```
