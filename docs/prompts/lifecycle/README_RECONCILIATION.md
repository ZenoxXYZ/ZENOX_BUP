# README Reconciliation Prompt

## Use

For early challenge transition or final README reconciliation.

```text
Read AGENTS.md, the Builder workflow, README lifecycle runbook, approved state files, README, phase/review records, code, tests, migrations, configuration, selected release path, deployment evidence if used, and Git evidence.

For early transition, update README from template orientation to approved challenge facts after problem.md/plan.md approval and execute.md initialization. For final reconciliation, update only verified features, architecture, setup, API overview where useful, migrations/tests, demo/release path, deployment if used, limitations, and deferrals. Do not claim planned or unverified behavior. Modify only README unless explicitly authorized otherwise; run Markdown/link checks and git diff --check. Do not commit or push.
```
