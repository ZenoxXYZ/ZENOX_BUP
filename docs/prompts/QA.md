# QA Prompt

Inspect the approved workstream, Critical Proof Path, relevant Interface / Assumption Contracts, real artifact, and existing verification. Verify the evaluation-contract-appropriate success, failures, boundaries, integration risks, and evidence limits. Add Golden Path and selected runtime checks for Product Build work. State what is proven, failed, deferred, and not verified. Do not claim E2E from unit or CI evidence alone.

Use [Integration Rendezvous](lifecycle/INTEGRATION_RENDEZVOUS.md) and the [E2E runbook](../runbooks/E2E.md) for assembled-flow checks.
